# Seu Espaço UnB (SeU)

Sistema web de consulta e reserva de espaços acadêmicos da FCTE/UnB, desenvolvido para a disciplina de Métodos de Desenvolvimento de Software (MDS) — 2026.1.

## Tecnologias

**Frontend:** React · TypeScript · Vite  
**Backend:** Java · Spring Boot · Spring Security · JWT  
**Banco de Dados:** MySQL  
**Ferramentas:** Git · GitHub · Docker · Render · Railway · MkDocs · Figma
